# Fundamentos de Deep Learning

Antes de construir nuestra primera red neuronal, repasaremos algunos conceptos
fundamentales sobre Machine Learning y aprenderemos cómo se representan los
datos que utilizaremos para entrenar nuestros modelos.

En este módulo estudiaremos:

- qué es Deep Learning,
- cómo se relaciona con Machine Learning,
- qué son las **features**,
- qué es una **label** o variable objetivo,
- cómo representamos los datos mediante $X$ e $y$,
- y cómo estos datos se convierten en las entradas de una red neuronal.
