# ¿Cómo aprende una red neuronal?

Ahora que conocemos la estructura de una red neuronal, estudiaremos cómo aprende
a partir de los datos.

Seguiremos paso a paso el proceso:

**Forward Pass → Loss → Backpropagation → Actualización de pesos**

Estudiaremos:

- forward propagation,
- funciones de pérdida,
- gradient descent,
- learning rate,
- backpropagation.
