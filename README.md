# Introducción a Deep Learning 2026

Taller práctico dirigido a profesores de escuela superior como continuación del taller de **Introducción a Machine Learning**.

En esta segunda parte se introducen conceptos de **Deep Learning**, incluyendo redes neuronales artificiales, **Deep Neural Networks (DNN)**, **Convolutional Neural Networks (CNN)** y técnicas básicas para entrenar, evaluar y mejorar modelos.

El enfoque continúa siendo práctico y accesible: el objetivo NO es convertir a los participantes en expertos en programación o en Deep Learning, sino brindarles las herramientas necesarias para **comprender estos modelos, experimentar con ellos y adaptar actividades para sus estudiantes**.

---

## Objetivos del Taller

Al finalizar el taller, el participante podrá:

* Comprender la diferencia entre Machine Learning tradicional y Deep Learning
* Entender la estructura básica de una red neuronal
* Identificar el papel de neuronas, capas, pesos, bias y funciones de activación
* Comprender de forma conceptual cómo se entrena una red neuronal
* Construir y entrenar una **Deep Neural Network (DNN)**
* Trabajar con imágenes como datos de entrada
* Comprender los principios fundamentales de las **Convolutional Neural Networks (CNN)**
* Entrenar y evaluar una CNN para clasificación de imágenes
* Reconocer problemas como overfitting y explorar estrategias para reducirlo
* Comparar diferentes arquitecturas y configuraciones de modelos
* Aplicar estos conceptos mediante proyectos guiados
* Adaptar actividades de Deep Learning para utilizarlas en el salón de clases

---

## Temas Principales

Durante el taller se explorarán temas como:

* Redes neuronales artificiales
* Funciones de activación
* Forward propagation
* Funciones de pérdida
* Gradient descent y backpropagation
* Epochs, batch size y learning rate
* Deep Neural Networks
* Convolutional Neural Networks
* Clasificación de imágenes
* Overfitting y regularización
* Data augmentation
* Introducción a Transfer Learning

---

## Metodología

El taller combina explicaciones conceptuales con actividades prácticas en **Jupyter Notebooks**.

Cada módulo incluye ejemplos ejecutables, visualizaciones y ejercicios diseñados para que los participantes puedan modificar parámetros, observar resultados y comprender cómo diferentes decisiones afectan el comportamiento de los modelos.

El énfasis estará en **aprender haciendo**.

---

## Requisitos

Se recomienda haber completado el taller de **Introducción a Machine Learning** o tener conocimientos básicos de:

* Python
* NumPy y Pandas
* Visualización de datos
* Entrenamiento y evaluación de modelos de Machine Learning
* Clasificación y regresión

No se requiere experiencia previa con redes neuronales o Deep Learning.
